# urdf_f_v2 하드웨어 검증 로그 (신모델)

이 폴더는 **신규 CAD(`URDF_description/`)** 를 MuJoCo 학습 모델로 변환하고 보행 학습을
진행한 기록이다. 구모델(`urdf_f`) 로그(`../` 의 00~130)의 후속이며, 동일한 형식
(목적 / 실행 명령 / 산출물 / 주요 수치 / 판단 / 다음 조치)을 따른다.

구모델과 **완전히 분리된 네임스페이스**(`urdf_f_v2`)로 진행하여 검증된 구모델 파이프라인을
동결한다.

## 📌 기록 규칙 (RULE — 반드시 준수)

신모델을 걷게 만드는 **모든 중간 과정**은 여기 기록으로 남긴다. 걷기 성공까지의
실험·수정·판단을 빠짐없이 축적하는 것이 목표다.

1. **의미 있는 단계·실험마다 새 문서**를 이 폴더에 다음 번호로 추가한다
   (`07_*.md`, `08_*.md`, … — 구모델 `../` 의 번호순 로그 방식 그대로).
2. **문서 형식은 구모델과 동일**하게: `목적 / 실행 명령 / 산출물 / 주요 수치 / 판단 / 다음 조치`.
   실패한 실험도 원인·판단과 함께 남긴다(구모델이 그렇게 했다).
3. **산출물 저장 위치**:
   - 영상·플롯·분석 → `outputs/urdf_f_v2/`
   - 학습 정책·체크포인트 → `outputs/train/urdf_f_v2/`
   - 설정(포즈·매핑 등) → `configs/urdf_f_v2/`
   - 코드 변경은 `envs/urdf_f_v2_env.py` / `rewards/urdf_f_v2_walking.py`에서만
     (구모델 코드 동결 — `06` 참조).
4. **새 문서를 아래 "단계별 문서" 인덱스에 반드시 추가**한다.
5. 걷기 성공 시: 보행 영상을 `outputs/urdf_f_v2/`에 저장하고 결과 문서로 정리한다.

## 현재 상태 (요약)

- ✅ 변환·매핑·접촉·물성·자세·안정 스탠딩·학습 파이프라인 **전부 완료**
- ✅ RL이 **안정 스탠딩 학습** (학습 전 24스텝 → 학습 후 50초, 낙하 없음)
- ⚠️ **보행 미달** — 서있기 지역최적에 갇힘(발 들림 6~7mm). 걷기는 구모델처럼
  커리큘럼 RL 캠페인 필요 (`05` 문서 참조)
- 🎬 영상: `outputs/urdf_f_v2/e2e_walk_v2model_standing.mp4` (50초 안정 스탠딩)

## 핵심 발견

구모델(9.2kg)과 달리 신모델은 초기에 서지 못했는데, 원인은 자세나 부호가 아니라
**URDF에 관절 damping/armature가 없어 변환 시 누락**된 것이었다. armature(모터 기어
반사 관성) = 0 이면 PD 제어가 폭주한다. 구모델과 동일한 값을 주입하자 즉시 안정
스탠딩이 됐다 (`03` 문서).
